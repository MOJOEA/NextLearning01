# My Next.js 14 Learning Journey

โปรเจกต์นี้จัดทำขึ้นเพื่อศึกษาและฝึกฝนการใช้งาน **Next.js 14** โดยเน้นการทำความเข้าใจฟีเจอร์หลักๆ เช่น App Router, Server Actions และการจัดการ Data Fetching

## สิ่งที่ได้เรียนรู้ (Learning Objectives)
- [ ] **App Router:** การจัดการ Routing แบบใหม่ด้วยโครงสร้าง Folder-based
- [ ] **Server & Client Components:** การแยกส่วนการทำงานเพื่อให้ประสิทธิภาพสูงสุด
- [ ] **Data Fetching:** การดึงข้อมูลผ่าน Server-side rendering (SSR) และ Static Site Generation (SSG)
- [ ] **Server Actions:** การส่งข้อมูลจาก Form ไปยัง Database โดยตรงโดยไม่ต้องสร้าง API Routes
- [ ] **Optimizing:** การจัดการ Images, Fonts และ Metadata เพื่อผลด้าน SEO

## Tech Stack
- **Framework:** [Next.js 14](https://nextjs.org) (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Database/ORM:** (ระบุเครื่องมือที่คุณใช้ เช่น Prisma / Supabase / MongoDB)
